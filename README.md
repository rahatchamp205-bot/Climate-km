# Climate-KM: Knowledge Base of the Climate Research Group

Welcome! This folder is the single place where our group stores methods,
data sources, findings, decisions, guides and meeting notes about urban
heat and flooding in Dhaka. Before writing anything, read [[00-Taxonomy]]
to learn the allowed categories, tags and naming rules. Save each new
note in the matching numbered folder, start it with the standard
front-matter block, and give it at least two tags. New volunteers should
begin with the 05-How-To folder, and anyone looking for the group's
latest choices should check 04-Decisions (newest date = latest).
All changes are tracked with Git, so commit your work with a clear message.
