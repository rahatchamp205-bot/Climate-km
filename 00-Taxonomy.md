# Climate-KM Taxonomy

This is the controlled vocabulary for the Climate Research Group.
Only use the categories and tags listed here. To add a new tag,
update this file first and commit the change.

## Categories (choose exactly ONE per note)
- Methods – how we collect or analyse data
- Data-Sources – where data comes from and how to access it
- Findings – results and insights from analysis
- Decisions – choices the group has agreed on
- How-To – step-by-step guides
- Meetings – meeting notes and action items

## Tags (choose AT LEAST TWO per note)
- #heat – urban heat, temperature
- #flooding – waterlogging, rainfall, floods
- #dhaka – anything specific to Dhaka
- #mirpur – anything specific to the Mirpur study area
- #interview – interviews or surveys with people
- #dataset – involves a specific dataset
- #urgent – needs attention soon
- #draft / #final – shown in the status field

## Rules
1. Every note must have 1 category and at least 2 tags.
2. Every note starts with the standard front-matter block
   (title, category, tags, date, author, status).
3. File names follow: YYYY-MM-DD-short-title.md
4. Dates are written as YYYY-MM-DD.
5. Status is either draft or final.
